- 位置：`ferro-analysis/src/dft/bader_grid.rs:679-704`（`step_offgrid`）、`:707-716`（`max_offgrid`）
- 描述：只在「新的最近格点密度 < 旧的」时才停：
  ```rust
  let pm = to_lat(chg, r_new);
  let p_old = to_lat(chg, *r);
  ...
  if rho_new < rho_old { return false; }
  *r = r_new; true
  ```
  如果步长小于该方向半个格距，`r` 会在极大格点两侧来回跳，最近格点一直不变，`rho_new == rho_old`，于是永远返回 `true`，
  直到 `max_iter = chg.nrho` 才停。默认 `stepsize` 取**最短**格步长，所以各轴格距相差两倍以上时，不传参数也会触发。
  结果本身没错（停下时最近格点就是极大值），只是慢：每个起点都要走满 nrho 步。

  |---|---|
  | 4×4×4 Å，各向同性，默认步长 | 0.008 s |
  | 2×2×6 Å（z 格距是 x 的 3 倍），默认步长 | 5.38 s |
  | 4×4×4 Å，`stepsize(0.02)` | 5.37 s |
